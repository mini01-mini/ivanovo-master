# Мастер — рабочий черновик

Мобильный веб-прототип сервиса поиска мастеров по ремонту.

## Сценарий клиента

1. Лента → «Создать заказ».
2. Выбор категории и описание проблемы.
3. Фото проблемы обязательно.
4. Адрес, бюджет и срочность.
5. Проверка заказа перед публикацией.
6. Получение предложений мастеров.
7. Профиль мастера: рейтинг, стаж, заказы, услуги, работы до/после, отзывы.
8. Выбор мастера.
9. Чат, привязанный к заказу.
10. Статусы: мастер едет → приехал → работа → завершено.
11. Отзыв только после завершённого заказа.

## Правила продукта

- Стоимость выезда указывает мастер.
- Дополнительные работы и запчасти согласуются до ремонта.
- Домашний адрес не публикуется в ленте.
- Отзыв привязан к завершённому заказу.

## Основные экраны

`index.html` — лента  
`create-order.html` — создание заказа  
`order-preview.html` — проверка заказа  
`offers.html` — предложения мастеров  
`master.html` — профиль мастера  
`confirm-master.html` — подтверждение выбора  
`chat.html` — чат  
`order-status.html` — статус заказа  
`review.html` — отзыв  
`messages.html` — сообщения  
`account.html` — аккаунт  
`settings.html` — настройки

## Текущий статус
